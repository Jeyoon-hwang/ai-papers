# Affordance Vision System - Test Scenarios

## 테스트 목표

실제 물건 10가지를 대상으로 affordance 인식 정확도, 신뢰도, 응답시간을 측정합니다.

---

## 테스트 물건 (10가지)

### 1️⃣ **책 (Book)**

**물리적 특성:**
- 직사각형 형태, 종이로 된 페이지
- 스택 가능, 가볍고 쉽게 이동 가능
- 손상 가능성 낮음

**예상 Affordance 점수:**
| 항목 | 예상 스코어 | 이유 |
|------|-----------|------|
| Graspable | 95% | 손잡기 쉬운 형태 |
| Stackable | 90% | 여러 권 쌓기 가능 |
| Insertable | 20% | 삽입할 장소 없음 |
| Placeable | 95% | 어느 곳에나 놓을 수 있음 |
| Moveable | 95% | 가볍고 쉽게 이동 |
| Fragile | 5% | 내구성 높음 |

**로봇 판단:**
> "이 물체는 안전하게 여러 권 쌓을 수 있으며, 필요한 위치로 쉽게 이동할 수 있습니다."

**테스트 환경:**
- 배경: 흰색/회색 책상
- 조명: 일반 실내 조명
- 카메라 거리: 30-50cm

## 평가 기준

### 1. **정확도 (Accuracy)**
예상 스코어와 실제 탐지 결과의 오차율
```
정확도 = 1 - |예상 - 실제| / 100
```

**목표:** 평균 85% 이상

### 2. **신뢰도 (Confidence)**
affordance 점수의 일관성
```
신뢰도 = 1 - (표준편차 / 평균)
```

**목표:** 평균 80% 이상

### 3. **응답시간 (Latency)**
전체 처리 시간

**목표:**
- 비전: 50ms 이하
- 추론: 300ms 이하
- 텍스트 생성: 500ms 이하
- **총합: 850ms 이하** (30 FPS)

## 기대 결과

### 우수 (Excellent)
- 정확도: ≥90%
- 신뢰도: ≥85%
- 응답시간: 모든 항목 목표 달성

### 양호 (Good)
- 정확도: 80-90%
- 신뢰도: 75-85%
- 응답시간: 총합 900ms 이하

### 보통 (Acceptable)
- 정확도: 70-80%
- 신뢰도: 65-75%
- 응답시간: 총합 1000ms 이하

### 부족 (Needs Improvement)
- 정확도: <70%
- 신뢰도: <65%
- 응답시간: >1000ms
